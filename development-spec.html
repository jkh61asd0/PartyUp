PartyUp 개발 명세서

게임을 같이 할 사람을 모집하고, 채팅과 게시판으로 소통하는 게임 매칭 SNS 웹앱

1. 한 줄 요약

PartyUp은 게임별 파티 모집, 친구, 채팅, 게시판, 신고 관리를 한 화면에서 제공하는 웹 서비스입니다.

2. 주요 기능

  • 닉네임 기반 로그인 및 프로필 설정
  • 게임, 나이, 성별, 마이크 여부로 파티 모집글 필터링
  • 파티 모집글 작성, 참여, 방 채팅, 방 설정
  • 친구 추가 및 개인 메시지
  • 게임별 게시판, 게시글 작성, 댓글 작성
  • 전체 로비 채팅
  • 사용자 차단, 신고, 관리자 제재 목록 관리
  • 테마, 화면 밀도, 채팅 표시 방식 등 사용자 설정

3. 기술 조건

HTML CSS JavaScript Node.js Vercel API Supabase 또는 Upstash Redis

  • 프론트엔드는 단일 페이지 방식으로 화면을 전환합니다.
  • 개인 설정은 브라우저 localStorage에 저장합니다.
  • 공유 데이터는 /api/state API로 저장하고 불러옵니다.
  • 로컬 실행 시 Node.js 서버와 db.json을 사용할 수 있습니다.
  • 배포 환경에서는 Supabase 또는 Upstash Redis를 저장소로 사용할 수 있습니다.

4. 데이터 구조

  • recruits: 파티 모집글 목록
  • boardPosts: 게시판 글과 댓글
  • lobbyMessages: 전체 채팅 메시지
  • reports: 신고 기록
  • bans: 관리자 제재 기록

5. 앞으로 더 추가할 방향

  • 실제 회원가입과 계정 인증 기능 추가
  • 실시간 채팅 성능 개선
  • 게임별 랭크, 포지션, 플레이 시간 조건 추가
  • 모바일 화면 최적화와 알림 기능 강화
  • 관리자 권한과 신고 처리 절차 세분화
